7. Perbaikan posisi tanda tangan Kepala Sekolah & Pengawas pada hasil

   Lampiran 2c (13 kolom) otomatis diperkecil supaya tetap muat rapi dalam
   1 halaman.

LANGKAH PEMASANGAN
-------------------
1. Backup dulu folder aplikasi & database (seperti biasa sebelum update).
2. Salin/timpa seluruh file dari update ini ke folder aplikasi (struktur
   folder di dalam zip ini PERSIS sama dengan struktur folder aplikasi).
3. TIDAK ADA migration baru pada update ini - TIDAK PERLU
   `php artisan migrate`.
4. TIDAK ADA pustaka Composer/npm baru pada update ini - TIDAK PERLU
   `composer install` maupun `npm install`. File hasil `npm run build`
   (folder `public/build/`) SUDAH TERMASUK di dalam zip ini karena CSS
   berubah (aturan bold baru) - user TIDAK PERLU menjalankan `npm run
   build` sendiri, cukup pastikan isi folder `public/build/` di server
   sudah tertimpa dengan isi zip ini.
5. Jalankan (disarankan, membersihkan cache lama):
   php artisan optimize:clear
6. Refresh browser (disarankan hard-refresh / Ctrl+F5 supaya file CSS/JS
   baru benar-benar terpakai, bukan versi lama dari cache browser).

CATATAN PENTING UNTUK DATA YANG SUDAH ADA
-------------------------------------------
- Poin 1 (No Whatsapp Kepala Sekolah) & Poin 2 (NUPTK/NIP): aturan format
  baru ini HANYA berlaku saat data BARU disimpan/diedit ulang - data lama
  yang sudah tersimpan dengan format lama TIDAK otomatis berubah/dihapus
  dan TIDAK memblokir aplikasi berjalan. Tapi begitu Admin OPS membuka
  ulang & menyimpan data yang formatnya tidak sesuai (mis. No WhatsApp
  Kepala Sekolah cuma 12 digit tanpa awalan "08", atau NUPTK bukan 16
  digit), sistem akan MEMINTA PERBAIKAN sebelum bisa disimpan ulang -
  Admin OPS/Admin BOSP terkait perlu diberi tahu untuk memperbaiki data
  itu sesuai format baru.
- Poin 3 (Photo OPS/SK OPS tidak muncul): perbaikan ini murni cara sistem
  MENAMPILKAN file yang sudah tersimpan sebelumnya (lewat route aplikasi,
  bukan link storage statis yang bergantung APP_URL) - file yang SUDAH
  ADA di server otomatis akan langsung muncul lagi setelah update ini
  dipasang, TIDAK PERLU upload ulang.
- Poin 5 (urutan dropdown & teks link Registrasi): murni tampilan, tidak
  mempengaruhi data yang sudah ada.
- Poin 7 (posisi tanda tangan PDF): hanya mempengaruhi TATA LETAK file PDF
  yang diunduh (bukan file Excel, yang formatnya sudah benar sejak
  sebelumnya) - tidak ada perubahan data.
