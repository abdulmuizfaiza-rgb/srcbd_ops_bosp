WAJIB DIBACA: Supaya Email Reset Password Benar-Benar Terkirim
------------------------------------------------------------------
Buka file `.env` di folder aplikasi, cari baris-baris `MAIL_...`, lalu isi
sesuai layanan email yang Anda pakai. Contoh paling umum & gratis (pakai
akun Gmail):

1. Aktifkan verifikasi 2 langkah di akun Gmail Anda (kalau belum).
2. Buat "App Password" khusus di https://myaccount.google.com/apppasswords
   (pilih aplikasi "Mail", nanti Google kasih kode 16 karakter). yinh epawlvawzvhi
3. Isi file `.env` seperti ini (ganti bagian dalam tanda kurung siku):

   MAIL_MAILER=smtp
   MAIL_HOST=smtp.gmail.com
   MAIL_PORT=587
   MAIL_USERNAME=[abdulmuizfaiza@gmail.com]
   MAIL_PASSWORD=[epawlvawzvhi]
   MAIL_ENCRYPTION=tls
   MAIL_FROM_ADDRESS=[komisariat.cibadak@gmail.com]
   MAIL_FROM_NAME="Aplikasi OPS_BOSP SR CBD"

4. Simpan file `.env`, lalu jalankan:
   php artisan config:clear
5. Coba lagi reset password salah satu akun Admin OPS/BOSP dari menu
   Kelola Pengguna - email seharusnya sudah benar-benar sampai (cek juga
   folder Spam/Promosi kalau belum kelihatan di kotak masuk utama).

Kalau Anda sudah punya email hosting sendiri (bukan Gmail, mis. dari
cPanel/domain sekolah), gunakan host/port/username/password SMTP dari
provider hosting email tersebut - biasanya ada di menu "Email Accounts"
panel hosting Anda, bukan Gmail.

Password hasil reset SELALU tetap ditampilkan di layar Superadmin setelah
klik "Reset Password" (baik email berhasil maupun gagal terkirim) - jadi
walau SMTP belum sempat diisi, Superadmin tetap bisa menyampaikan password
itu secara manual (WhatsApp/lisan/dll) ke Admin OPS/BOSP yang bersangkutan.

LANGKAH PEMASANGAN
-------------------
1. Backup dulu folder aplikasi & database (seperti biasa sebelum update).
2. Salin/timpa seluruh file dari update ini ke folder aplikasi.
3. TIDAK ADA migration baru pada update ini - TIDAK PERLU
   `php artisan migrate`.
4. TIDAK ADA pustaka Composer/npm baru pada update ini - TIDAK PERLU
   `composer install`/`npm install`. File hasil `npm run build` (folder
   `public/build/`) SUDAH TERMASUK di dalam zip ini (CSS berubah sedikit
   karena style ikon baru) - tidak perlu build ulang sendiri.
5. Jalankan: php artisan optimize:clear
6. Ikuti bagian "WAJIB DIBACA" di atas untuk mengisi SMTP asli supaya
   email reset password benar-benar terkirim.
7. Refresh browser (disarankan hard-refresh / Ctrl+F5).
